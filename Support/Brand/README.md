# DevWatch logo

`devwatch-logo.png` is the logo and source image for the macOS app icon. It has a transparent background, a dark terminal tile, a white prompt, and a green activity dot. The dot in the logo is a fixed brand element; the menu bar icon separately displays the dynamic process status.

`scripts/build-app.sh` generates standard and Retina sizes from 16 to 1024 pixels and bundles them into `DevWatch.icns`. The original PNG remains unchanged.

Created with the integrated Imagegen tool on September 8, 2026.

## Generation prompt

Use case: logo-brand. Create a single polished macOS application icon for DevWatch, a minimal developer utility that watches source files and automatically starts frontend dev servers. Square 1024x1024 image. A dark graphite rounded-square macOS tile with subtle premium bevel and soft controlled shading, centered with generous transparent outer padding. Inside: a large crisp warm-white terminal prompt chevron and underscore, optically balanced, bold simple geometry readable at 32px. A vivid green circular activity indicator at the lower-right of the terminal mark, integrated with a small dark separating rim. Terminal and active status should form one distinctive calm mark. Front facing, no perspective. Minimal restrained native Mac aesthetic, no clutter, no words, no letters, no watermark, no extra mockup, no scenic background. Truly transparent pixels outside the rounded-square tile; do not render checkerboard. The tile occupies about 82 percent of canvas width.
